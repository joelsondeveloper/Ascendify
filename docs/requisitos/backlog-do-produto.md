# Critérios de Priorização

As funcionalidades serão organizadas utilizando o método **MoSCoW**.

* **Must Have** → Essenciais para o funcionamento do produto.
* **Should Have** → Muito importantes, mas podem ser implementadas após as funcionalidades essenciais.
* **Could Have** → Agregam valor, porém não impedem o uso do sistema.
* **Won't Have** → Funcionalidades planejadas para versões futuras.
