# Requisitos Funcionais

# Módulo de Autenticação

**RF001** - O sistema deve permitir que usuários se cadastrem utilizando e-mail e senha.

**RF002** - O sistema deve permitir autenticação utilizando conta Google.

**RF003** - O sistema deve permitir que usuários realizem login utilizando e-mail e senha.

**RF004** - O sistema deve permitir recuperação de senha através de e-mail.

**RF005** - O sistema deve permitir que usuários encerrem suas sessões (logout).

---

# Módulo de Perfil

**RF006** - O sistema deve permitir que usuários visualizem e editem seu perfil.

**RF007** - O sistema deve exibir informações do usuário, incluindo nome, foto, nível, XP, idade, moedas, itens, título atual e capítulo ativo.

**RF008** - O sistema deve permitir atualização de foto de perfil.

---

# Módulo de Capítulos (Arcos)

**RF009** - O sistema deve permitir que usuários criem capítulos (arcos) de evolução pessoal.

**RF010** - O sistema deve permitir que um capítulo possua múltiplos objetivos associados.

**RF011** - O sistema deve permitir que apenas um capítulo esteja ativo por vez.

**RF012** - O sistema deve permitir concluir um capítulo quando seus objetivos forem alcançados.

---

# Módulo de Missões

**RF013** - O sistema deve permitir que usuários criem missões.

**RF014** - O sistema deve permitir classificar missões como principais ou secundárias.

**RF015** - O sistema deve permitir criar missões recorrentes.

**RF016** - O sistema deve permitir criar missões não recorrentes.

**RF017** - O sistema deve permitir marcar missões como concluídas.

**RF018** - O sistema deve registrar falhas no cumprimento das missões.

---

# Módulo de Rotinas

**RF019** - O sistema deve permitir criação manual de rotinas.

**RF020** - O sistema deve permitir criação automática de rotinas utilizando Inteligência Artificial.

**RF021** - O sistema deve permitir a readequação dinâmica da rotina diante de mudanças inesperadas.

**RF022** - O sistema deve recalcular automaticamente futuras atividades considerando histórico recente de execução.

---

# Módulo de Progressão

**RF023** - O sistema deve conceder experiência ao usuário ao concluir missões principais.

**RF024** - O sistema deve permitir evolução de níveis baseada na experiência acumulada.

**RF025** - O sistema deve reduzir recompensas quando o usuário falhar em missões.

**RF026** - O sistema deve manter registro do histórico de evolução do usuário.

---

# Módulo de Bosses

**RF027** - O sistema deve permitir criação de bosses associados aos capítulos.

**RF028** - O sistema deve permitir registrar bosses derrotados.

**RF029** - O sistema deve permitir a existência de bosses principais e secundários.

**RF030** - O sistema deve recompensar usuários ao derrotarem bosses.

---

# Módulo de Economia

**RF031** - O sistema deve conceder moedas ao usuário ao concluir missões secundárias.

**RF032** - O sistema deve conceder moedas ao derrotar bosses.

**RF033** - O sistema deve permitir utilização de moedas na loja.

---

# Módulo de Loja e Inventário

**RF034** - O sistema deve possuir uma loja virtual interna.

**RF035** - O sistema deve permitir aquisição de itens utilizando moedas do sistema.

**RF036** - O sistema deve armazenar itens adquiridos no inventário do usuário.

**RF037** - O sistema deve permitir utilização de habilidades e itens especiais.

---

# Módulo de Títulos

**RF038** - O sistema deve gerar títulos dinâmicos baseados nas conquistas do usuário.

**RF039** - O sistema deve exibir o título atual no perfil do usuário.

---

# Módulo de Inteligência Artificial

**RF040** - O sistema deve utilizar Inteligência Artificial para auxiliar na criação de rotinas.

**RF041** - O sistema deve utilizar Inteligência Artificial para analisar o progresso do usuário.

**RF042** - O sistema deve utilizar Inteligência Artificial para sugerir melhorias ao usuário.

**RF043** - O sistema deve continuar operando mesmo na indisponibilidade dos serviços de Inteligência Artificial.

---

# Funcionalidades Futuras

**RF044** - O sistema poderá permitir criação de guildas.

**RF045** - O sistema poderá permitir interação social entre usuários.

**RF046** - O sistema poderá disponibilizar rankings globais.
