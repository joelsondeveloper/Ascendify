# Requisitos Não Funcionais

# Segurança

**RNF001** - O sistema deve armazenar senhas utilizando algoritmos de criptografia seguros.

**RNF002** - O sistema deve exigir autenticação para acesso às funcionalidades protegidas.

**RNF003** - O sistema deve proteger rotas privadas contra acesso não autorizado.

**RNF004** - O sistema deve proteger dados sensíveis dos usuários.

---

# Armazenamento

**RNF005** - O sistema deve permitir que o usuário escolha entre armazenamento local ou armazenamento em nuvem.

**RNF006** - Quando configurado para armazenamento local, os dados do usuário não deverão ser enviados para servidores externos.

**RNF007** - O sistema deve sincronizar dados na nuvem quando o usuário optar pelo armazenamento remoto.

---

# Desempenho

**RNF008** - O sistema deve responder às principais interações do usuário em até 2 segundos em condições normais de uso.

**RNF009** - O sistema deve otimizar carregamentos para minimizar tempo de espera.

**RNF010** - O sistema deve utilizar carregamento otimizado de recursos sempre que possível.

---

# Disponibilidade

**RNF011** - O sistema deve continuar funcionando mesmo quando serviços de Inteligência Artificial estiverem indisponíveis.

**RNF012** - O sistema deve disponibilizar mecanismos alternativos para criação de missões e rotinas sem dependência de IA.

---

# Compatibilidade

**RNF013** - O sistema deve ser responsivo e funcionar corretamente em desktops, tablets e smartphones.

**RNF014** - O sistema deve ser compatível com os principais navegadores modernos.

---

# Acessibilidade

**RNF015** - O sistema deve seguir boas práticas de acessibilidade.

**RNF016** - O sistema deve permitir navegação utilizando teclado.

**RNF017** - O sistema deve apresentar contraste adequado entre elementos visuais.

**RNF018** - O sistema deve fornecer textos alternativos para conteúdos visuais relevantes.

---

# Escalabilidade

**RNF019** - O sistema deve ser desenvolvido considerando crescimento gradual da base de usuários.

**RNF020** - A arquitetura deve permitir expansão horizontal e vertical.

---

# Internacionalização

**RNF021** - O sistema deve ser desenvolvido preparado para suportar múltiplos idiomas no futuro.

**RNF022** - Inicialmente o idioma padrão do sistema será Português do Brasil.

---

# Tecnologias

**RNF023** - O front-end deve ser desenvolvido utilizando Next.js e TypeScript.

**RNF024** - O back-end deve ser desenvolvido utilizando Express.js.

**RNF025** - O sistema deve utilizar MongoDB como banco de dados principal.

**RNF026** - O sistema deve utilizar Tailwind CSS para estilização.

---

# Confiabilidade

**RNF027** - O sistema deve evitar perda de dados do usuário.

**RNF028** - O sistema deve manter consistência dos dados durante operações críticas.

---

# Manutenibilidade

**RNF029** - O sistema deve seguir padrões de código que facilitem manutenção e evolução.

**RNF030** - O sistema deve possuir documentação técnica atualizada.
