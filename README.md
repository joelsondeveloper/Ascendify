# Ascension System

Ascension System is a gamified personal development platform inspired by Solo Leveling.

The goal of the project is to transform real-life activities into quests, allowing users to evolve their character through experience points, levels, achievements, and challenges.

## Project Status

🚧 In Requirements Analysis Phase

## Main Features (Planned)

- User authentication
- Character profile
- Experience and level system
- Daily and weekly quests
- Attributes and skills
- Achievement system
- Inventory and rewards
- Rankings and titles
- Progress dashboard

## Tech Stack (Planned)

- React
- TypeScript
- Node.js
- PostgreSQL
- Prisma
- Tailwind CSS
